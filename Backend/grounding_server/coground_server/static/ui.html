Objects

Objects the server has received (scene.update). Choosing a "Destination" creates a step that carries the object there (plan.place). Rules aren't consulted.

Plan

Gray: move · Blue: pick · Green: place. Click a bar or a Plan row to jump to that time. In the diagram, the dashed line is the base's path, the translucent circle is the base, and the dashed square is the carried object.

Execution

First plan with "Build Plan (motion plan)", check it on the sequence bar, then "Execute" (exec.*). It moves as planned and replans on the spot if things have shifted. You can change destinations in the "Objects" table above even during execution. Per-step "Skip" / "Retry" are in the Plan table.

Robot unit test

Runs a single skill without the Plan or motion planning (robot.*). Unavailable while the Plan is executing.

MoveIt: grasp in place

Assumes the robot is in front of the desk (the base doesn't move). For objects received from Unity (scene.update), "Plan" plans without moving (Unity's Ghost plays it back) and "Pick" grasps and lifts on the spot. If there's a plan, it follows that trajectory.

Nav: move to Goal
